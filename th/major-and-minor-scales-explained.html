อธิบายสเกลเมเจอร์และไมเนอร์

สเกลเมเจอร์และไมเนอร์ต่างกันที่รูปแบบของเสียงเต็มและครึ่งเสียงภายใน นี่คือรูปแบบนั้น ไมเนอร์สามแบบ และทำไมโน้ตตัวที่สามจึงสำคัญ

2026-05-12

คำตอบสั้น ๆ

บันไดเสียงเมเจอร์คือรูปแบบขั้นที่ตายตัว: เต็มเสียง เต็มเสียง ครึ่งเสียง เต็มเสียง เต็มเสียง เต็มเสียง ครึ่งเสียง บันไดเสียงไมเนอร์ลดขั้นที่สาม หก และเจ็ดของรูปแบบนั้นลง โน้ตตัวที่สามที่ต่ำลงคือสิ่งที่หูของคุณได้ยินเป็นความแตกต่างระหว่างสดใสกับมืดหม่น

บันไดเสียงคือรูปแบบ ไม่ใช่รายชื่อโน้ต

คนส่วนใหญ่รู้จักบันไดเสียงเมเจอร์ครั้งแรกในฐานะเสียง do re mi หรือคีย์สีขาวจาก C ขึ้นไปถึง C ทั้งสองอย่างถูกต้อง แต่ไม่ใช่นิยามที่มีประโยชน์ นิยามที่มีประโยชน์คือรูปแบบของระยะห่าง

สองคำก่อน ครึ่งเสียง (semitone) คือขั้นปกติที่เล็กที่สุดในดนตรีตะวันตก คือระยะจากคีย์เปียโนตัวใดก็ได้ไปยังคีย์ถัดไปทันที ไม่ว่าสีดำหรือสีขาว เต็มเสียง (tone) คือสองครึ่งเสียง บนดับเบิลเบส ครึ่งเสียงในโพสิชันต่ำมีระยะประมาณช่องระหว่างนิ้วที่อยู่ติดกัน เต็มเสียงมีระยะประมาณจากนิ้วที่หนึ่งถึงนิ้วที่สาม

รูปแบบเมเจอร์ นับขึ้นจากโน้ตเริ่มต้น คือ: เต็มเสียง เต็มเสียง ครึ่งเสียง เต็มเสียง เต็มเสียง เต็มเสียง ครึ่งเสียง ใช้จาก C คุณจะได้ C, D, E, F, G, A, B, C ซึ่งบังเอิญเป็นคีย์สีขาวทั้งหมด ใช้รูปแบบเดียวกันทุกประการจาก D คุณจะได้ D, E, F ชาร์ป, G, A, B, C ชาร์ป, D ชาร์ปไม่ใช่ของตกแต่ง มันคือสิ่งที่จำเป็นเพื่อรักษารูปแบบไว้ และรูปแบบคือสิ่งที่ทำให้เสียงเป็นเมเจอร์ที่จำได้

บันไดเสียงไมเนอร์และโน้ตตัวที่สามที่ต่ำลง

บันไดเสียงเนเชอรัลไมเนอร์ใช้ตัวอักษรเจ็ดตัวเดิม และลดขั้นที่สาม หก และเจ็ดลงขั้นละครึ่งเสียง C major คือ C, D, E, F, G, A, B C natural minor คือ C, D, E แฟลต, F, G, A แฟลต, B แฟลต

ในสามการเปลี่ยนแปลงนั้น โน้ตตัวที่สามทำงานด้านอารมณ์เกือบทั้งหมด ระยะจาก C ขึ้นไป E คือสี่ครึ่งเสียง เรียกว่าคู่สามเมเจอร์ ระยะจาก C ขึ้นไป E แฟลตคือสามครึ่งเสียง คู่สามไมเนอร์ ครึ่งเสียงเดียวนั้นคือความแตกต่างทั้งหมดระหว่างเสียงที่ผู้ฟังส่วนใหญ่เรียกว่าสดใส กับเสียงที่ผู้ฟังส่วนใหญ่เรียกว่ามืด เศร้า หรือจริงจัง คุณทดสอบได้ในราวสี่วินาทีบนคีย์บอร์ดใดก็ได้: เล่น C, E, G แล้วเล่น C, E แฟลต, G ไม่มีอะไรอื่นเปลี่ยนเลย

ควรต้านทานการสรุปง่าย ๆ ว่าไมเนอร์เท่ากับเศร้า ดนตรีเต้นรำจำนวนมาก แทงโก้ส่วนใหญ่ และบทเพลงโฟล์กยุโรปตะวันออกส่วนใหญ่อยู่ในไมเนอร์ และไม่เศร้าเลย ไมเนอร์คือสีสัน ไม่ใช่อารมณ์

ทำไมไมเนอร์จึงมีสามรูปแบบ

เนเชอรัลไมเนอร์มีจุดอ่อนในทางปฏิบัติหนึ่งข้อ ขั้นที่เจ็ดของมันอยู่ต่ำกว่าโทนิก ซึ่งเป็นโน้ตบ้าน หนึ่งเสียงเต็ม ใน C minor ขั้นที่เจ็ดนั้นคือ B แฟลต และ B แฟลตไม่ได้โน้มเข้าหา C อย่างเร่งด่วนเลย ดนตรีที่ต้องการการมาถึงอย่างเด็ดขาดต้องการโน้ตที่ต่ำกว่าบ้านครึ่งเสียง โน้ตที่ฟังไม่จบจนกว่าจะคลี่คลาย

ฮาร์โมนิกไมเนอร์จึงยกขั้นที่เจ็ดกลับขึ้นไป: C, D, E แฟลต, F, G, A แฟลต, B เนเชอรัล, C โน้ต B เนเชอรัลดึงเข้าหา C อย่างแรง และคอร์ดโดมิแนนต์ที่สร้างบน G กลายเป็นคอร์ดเมเจอร์ ซึ่งเป็นสิ่งที่ทำให้เคเดนซ์ในคีย์ไมเนอร์มีความคม ราคาที่ต้องจ่ายคือช่องว่างระหว่าง A แฟลตกับ B เนเชอรัล สามครึ่งเสียง ขั้นคู่ที่ฟังแปลกหูอย่างชัดเจนและร้องยาก

เมโลดิกไมเนอร์ทำให้ช่องว่างนั้นราบรื่นโดยยกขั้นที่หกขึ้นด้วยเมื่อแนวทำนองขาขึ้น: C, D, E แฟลต, F, G, A เนเชอรัล, B เนเชอรัล, C ตามธรรมเนียม มันจะกลับไปเป็นเนเชอรัลไมเนอร์ในขาลง เพราะแนวทำนองขาลงไม่จำเป็นต้องโน้มเข้าหาโทนิก ในแนวปฏิบัติของแจ๊ส รูปแบบที่ยกขึ้นมักใช้ทั้งสองทิศ สามรูปแบบ บันไดเสียงเดียว แต่ละแบบแก้ปัญหาต่างกัน

Relative และ parallel

ความสัมพันธ์สองแบบนี้ควรเรียกชื่อให้ชัด เพราะถูกสับสนกันตลอดเวลา คีย์ relative ใช้เครื่องหมายประจำกุญแจเดียวกัน C major และ A minor ไม่มีชาร์ปหรือแฟลตทั้งคู่ relative minor เริ่มต่ำกว่าเมเจอร์คู่สามไมเนอร์เสมอ ทั้งสองมีโน้ตเหมือนกันทุกตัว และต่างกันเพียงว่าดนตรีถือว่าโน้ตตัวไหนเป็นบ้าน

คีย์ parallel ใช้โทนิกเดียวกันแทน C major และ C minor เริ่มที่ C ทั้งคู่ แต่มีเครื่องหมายประจำกุญแจต่างกัน ห่างกันสามแฟลต คีตกวีสลับระหว่างคีย์ parallel เพื่อผลทางดราม่าทันที เพราะโน้ตบ้านยังอยู่ที่เดิมขณะที่สีสันพลิกผัน Schubert สร้างอาชีพครึ่งหนึ่งของเขาบนสิ่งนี้

บันไดเสียงบนเครื่องดนตรี

บนแอคคอร์เดียนแบบปุ่มโครมาติกหรือบายัน นิ้วของบันไดเสียงจะซ้ำกันในทุกคีย์ ซึ่งคนเล่นเปียโนอาจรู้สึกว่าไม่ค่อยยุติธรรมนัก เพราะการจัดวางปุ่มมีความสมมาตร รูปนิ้วของบันไดเสียงเมเจอร์ที่เริ่มจาก C จึงเป็นรูปเดียวกับที่เริ่มจาก F ชาร์ป เพียงแค่ย้ายทั้งรูปไปบนแผงปุ่ม เรียนรูปนิ้วครั้งเดียวก็ได้ครบสิบสองคีย์ นี่คือเหตุผลที่ผู้เล่นแบบปุ่มมักซ้อมบันไดเสียงในคีย์ที่นักเปียโนมองว่าโหดร้ายได้โดยไม่รู้ตัว

บนเปียโนแอคคอร์เดียน นิ้วจะเปลี่ยนไปตามคีย์เหมือนบนเปียโน แต่มือซ้ายให้ผลตอบแทนที่คุ้มค่า: แผงระบบเบส Stradella ให้เสียงพื้นฐานของแต่ละขั้นในบันไดเสียงด้วยรูปแบบที่คาดเดาได้ และโทนิก ซับโดมินันต์ และโดมินันต์ของทุกคีย์อยู่ห่างกันไม่เกินสามปุ่ม ซ้อมบันไดเสียงมือขวาพร้อมกับแถวคอร์ดมือซ้าย แล้วคีย์จะกลายเป็นตำแหน่งที่จับต้องได้ ไม่ใช่แค่ข้อเท็จจริง

บนดับเบิลเบส บันไดเสียงเป็นการฝึกความแม่นยำของระดับเสียงไปในตัว เพราะไม่มีเฟร็ตและไม่มีอะไรให้หลบซ่อน เล่นช้า ๆ หยุดที่โน้ตแต่ละตัว แล้วเทียบกับสายเปล่าทุกครั้งที่ทำได้: ในคีย์ G เมเจอร์ ให้เล่นสาย G เปล่าและสาย D เปล่าคู่กับโน้ตที่กดนิ้ว แล้วฟังจนเสียงสั่นกระเพื่อมหายไป นี่ไม่ใช่แบบฝึกหัดสำหรับมือใหม่ นักดนตรีวงออร์เคสตราที่ A&G Academy ทำแบบนี้ก่อนซ้อมวง และคนที่มีวิจารณญาณทุกคนก็ทำเช่นกัน

คำถามที่พบบ่อย

เมเจอร์กับไมเนอร์ต่างกันจริง ๆ อย่างไร

ต่างกันที่รูปแบบของเต็มเสียงและครึ่งเสียง ไมเนอร์ลดขั้นที่สาม หก และเจ็ดของบันไดเสียงเมเจอร์ลงครึ่งเสียง ขั้นที่สามทำหน้าที่ส่วนใหญ่ที่หูได้ยิน: คู่สามเมเจอร์อยู่สูงกว่าโทนิกสี่ครึ่งเสียง คู่สามไมเนอร์อยู่สูงกว่าสามครึ่งเสียง เล่น C, E, G แล้วตามด้วย C, E แฟลต, G คุณจะได้ยินความต่างทันที

ควรซ้อมบันไดเสียงไมเนอร์แบบไหน

เรียนเนเชอรัลไมเนอร์ก่อน เพราะตรงกับเครื่องหมายประจำคีย์และไม่ต้องคิดเพิ่ม จากนั้นเพิ่มฮาร์โมนิกไมเนอร์ เพราะเป็นรูปแบบที่สร้างคอร์ดที่คุณจะพบจริงในเพลงคีย์ไมเนอร์ เมโลดิกไมเนอร์มาเป็นลำดับที่สาม และสำคัญที่สุดสำหรับการเขียนทำนองและการด้นสดแบบแจ๊ส

ต้องใช้เวลานานแค่ไหนจึงจะเรียนบันไดเสียงได้ครบ

หากซ้อมอย่างตั้งใจวันละสิบนาที ผู้เรียนผู้ใหญ่ส่วนใหญ่จะเล่นคีย์เมเจอร์ที่ใช้บ่อยได้มั่นคงภายในไม่กี่เดือน และครบทั้งสิบสองคีย์ภายในราวหนึ่งปี ผู้เล่นแอคคอร์เดียนแบบปุ่มมักไปได้เร็วกว่า เพราะรูปนิ้วเดียวใช้ได้กับทุกคีย์ ความเร็วไม่ใช่เป้าหมาย เป้าหมายคือเสียงที่สม่ำเสมอและระดับเสียงที่แม่นยำ
