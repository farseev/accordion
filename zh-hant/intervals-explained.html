音程詳解

音程是兩個音之間的距離，由數出來的字母數和性質共同命名。怎樣給任何一個音程命名，又怎樣不用數就把它聽出來。

2026-05-20

一句話回答

音程是兩個音之間的距離。它有兩個部分：一個數字，從較低的音數到較高的音，連同兩端的字母名稱一起算；以及一個性質，例如大、小、純、增或減，用來說明它確切有幾個半音。

數出度數

要找出度數，就從下面的音數到上面的音，兩端都要算進去。從 C 到 E，你數 C、D、E，三個字母，所以這個音程是三度。從 C 到 G，你數 C、D、E、F、G，五個字母，是五度。從 C 到上方的 C，八個字母，是八度。

包含兩端的數法一開始幾乎會絆倒每個人，因為這表示一個音到它自己是一度，稱為同度，而不是零度。值得安慰的是，這個慣例已經有好幾百年，現在也不會有人去改它了。

要注意，度數完全不考慮升降記號。C 到 E 是三度。C 到 E♭ 也是三度。C♯ 到 E 仍然是三度。字母相同，度數就相同。改變的是名稱的後半部。

性質，以及為什麼分成兩個家族

性質告訴你確切的大小。音程分為兩個表現不同的家族，這是歷史的傳承，而不是有人故意刁難。

同度、四度、五度和八度稱為純音程。它們的頻率比最簡單，同時發聲時融合得最徹底。純五度是七個半音，例如 C 往上到 G。純四度是五個半音，C 往上到 F。八度是十二個半音。

二度、三度、六度和七度有大、小兩種版本，相差一個半音。大三度是四個半音，C 到 E；小三度是三個，C 到 E♭。大六度是九個半音，C 到 A；小六度是八個，C 到 A♭。大二度是兩個半音，C 到 D；小二度是一個，C 到 D♭，這是最小的一步。

把任何音程再縮小一個半音，就成為減音程。再擴大一個半音，就成為增音程。純五度 C 到 G 縮窄成 C 到 G♭，就是減五度：六個半音，中世紀理論家稱它為「音樂中的魔鬼」，也正是它讓屬七和弦充滿不安。

不靠數就聽出音程

數算在紙上沒問題，在即時演奏中卻毫無用處。你需要的是辨認，而標準的方法是把每個音程連結到一首你已經熟悉的曲子，讓聲音一出現就帶著標籤。

小二度是《大白鯊》的鯊魚主題。大二度是《生日快樂》的開頭。大三度是《聖者進行曲》的開頭。純四度是結婚進行曲或《驪歌》的頭兩個音。純五度是《星際大戰》的主題，或《小星星》的開頭。大六度是 NBC 台呼鈴聲的開頭，八度則是《彩虹之上》。

用你真正熟悉的曲子，而不是別人傳下來的清單。也要練習下行音程，這幾乎每個人都忽略，而且難得多。下行小六度和下行純五度很容易混淆，除非你刻意練習過。

音程是和弦的原料

和弦是疊起來的音程，所以練音程的回報來得特別快。大三和弦是一個大三度上面疊一個小三度：C 到 E 是四個半音，E 到 G 是三個，而外側的 C 到 G 是純五度。小三和弦則是同樣的組件反過來排，先小三度再大三度：C 到 E♭，再從 E♭ 到 G。

減三和弦疊兩個小三度，C、E♭、G♭，它的外側音程就是那個不穩定的減五度。增三和弦疊兩個大三度，C、E、G♯。四種三和弦，一旦掌握了音程，每一種都能用一句話說清楚。

再往上的一切也遵循同樣的邏輯。屬七和弦是大三和弦上方加一個小七度，距離根音十個半音。學會音程，和弦構成就不再需要死記硬背。

樂器上的音程

低音提琴讓音程變成身體可以感受的東西，這是很少樂器做得到的。它的空弦以純四度定弦，E、A、D、G，彼此相隔五個半音，所以一個四度就是旁邊的下一條弦。在較低的把位，你的手自然涵蓋一個全音，從一指到四指；再大就要換把。拇指把位位於琴弦變短的高處，改變了幾何關係：同樣的實際伸展現在能涵蓋寬得多的音程，這正是它存在的原因。

泛音讓音程成為聽得見的物理學。在低音提琴弦的正中央輕觸，就會奏出比空弦高八度的音；在三分之一處輕觸，則得到八度加五度。定義八度為二比一、五度為三比二的頻率比，就在你的手指底下。

在手風琴上，半音階按鈕的排列以小三度安排各排，所以減七和弦在整個鍵盤上就是一個筆直的指型，移調只是移動這個指型而已。在左手，Stradella 的基礎低音排是一連串的純五度：往一個方向一個按鈕永遠是上行五度，往另一個方向永遠是下行五度。A&G Academy 的學生常說，當他們發現自己的左手一直都在以五度行走時，音程這件事才終於豁然開朗。

常見問題

C 到 E 只有兩步，為什麼是三度？

因為音程的度數是把字母名稱連同起點和終點一起數的。C、D、E 是三個字母，所以這個音程是三度。這是命名慣例，而不是步數的測量；名稱的另一半，也就是大或小，才表示以半音計算的確切大小。

增四度和減五度有什麼不同？

在聲音上沒有差別：兩者都跨六個半音，在鍵盤上就是同樣的兩個鍵。差別在於寫法和功能。C 到 F♯ 是增四度，通常向外解決；C 到 G♭ 是減五度，通常向內解決。哪種寫法正確，由上下文決定。

如何提升聽辨音程的能力？

每天短時間練習，而不是一次練很久，先只練三個音程，等它們穩定了再增加。每個音程先唱出來再核對，因為唱歌迫使你真正在內心聽見它。從一開始就納入下行音程，因為它們比較難，而且通常會被一直延後，直到成為真正的弱點。
