大調與小調音階詳解

大調和小調的區別，在於音階內部全音和半音的排列。這裡講清楚那個排列、小調的三種形式，以及三級音為什麼最關鍵。

2026-05-12

一句話回答

大調音階是固定的步距模式：全音、全音、半音、全音、全音、全音、半音。小調音階則把這個模式的第三、第六和第七級降低。降低的三級音，就是你的耳朵聽到的明亮與陰暗之間的差別。

音階是一種模式，而不是一串音名

多數人第一次接觸大調音階，是 do re mi 的聲音，或是從 C 到 C 的白鍵。兩者都對，但都不是有用的定義。有用的定義是一種距離的模式。

先說兩個詞。半音是西方音樂中最小的一般步距，也就是鋼琴上任何一個鍵到緊鄰下一個鍵的距離，不論黑鍵或白鍵。全音是兩個半音。在低音提琴上，低把位的一個半音大約是相鄰兩指之間的距離；一個全音大約是一指到三指的距離。

從起始音往上數，大調的模式是：全音、全音、半音、全音、全音、全音、半音。從 C 開始套用，會得到 C、D、E、F、G、A、B、C，剛好全是白鍵。從 D 開始套用完全相同的模式，會得到 D、E、F♯、G、A、B、C♯、D。升記號不是裝飾，而是維持這個模式所必需的，而正是這個模式，讓聲音一聽就是大調。

小調音階與降低的三級音

自然小調音階用同樣的七個字母，把第三、第六和第七級各降低一個半音。C 大調是 C、D、E、F、G、A、B。C 自然小調是 C、D、E♭、F、G、A♭、B♭。

這三處改變中，三級音幾乎承擔了所有的情緒工作。從 C 往上到 E 是四個半音，稱為大三度。從 C 往上到 E♭ 是三個半音，稱為小三度。就這一個半音，造成了多數聽眾稱為明亮的聲音，和多數聽眾稱為陰暗、悲傷或嚴肅的聲音之間的全部差別。在任何鍵盤上大約四秒鐘就能驗證：彈 C、E、G，再彈 C、E♭、G。其他什麼都沒變。

值得抗拒「小調等於悲傷」這種簡化說法。大量的舞曲、大部分的探戈，以及東歐民謠曲目中的一大部分，都是小調，卻一點也不悲傷。小調是一種色彩，而不是一種情緒。

為什麼小調有三種形式

自然小調有一個實際的弱點。它的第七級在主音（也就是「家」的那個音）下方一個全音。在 C 小調中，第七級是 B♭，而 B♭ 並不會急切地傾向 C。想要明確抵達的音樂，需要一個在主音下方半音的音，一個在解決之前聽起來都還沒結束的音。

所以和聲小調把第七級升回來：C、D、E♭、F、G、A♭、B♮、C。B♮ 強烈地拉向 C，而建立在 G 上的屬和弦變成大三和弦，這就是小調終止式那股力道的由來。代價是 A♭ 和 B♮ 之間三個半音的空隙，這個音程聽起來明顯帶有異國風味，唱起來也很彆扭。

旋律小調在旋律上行時把第六級也升高，藉此填平那個空隙：C、D、E♭、F、G、A♮、B♮、C。傳統上，下行時它會回到自然小調，因為下行的線條不需要傾向主音。在爵士的實際運用中，升高的形式常常上下行都用。三種形式，同一個音階，各自解決不同的問題。

關係調與同主音調

有兩種關係值得說清楚，因為它們經常被搞混。關係調共用同一個調號。C 大調和 A 小調都沒有升降記號；關係小調總是從大調主音往下一個小三度開始。它們包含完全相同的音，差別只在於音樂把哪個音當作「家」。

同主音調則是共用主音。C 大調和 C 小調都從 C 開始，但調號不同，相差三個降記號。作曲家會在同主音調之間切換，以達到立即的戲劇效果，因為「家」的音不變，色彩卻大幅擺盪。Schubert 靠這一手撐起了半個職業生涯。

回到樂器上練音階

在半音階按鍵式手風琴或巴揚上，音階指法在各調之間重複的方式，會讓彈鋼琴的人覺得有點不公平。因為按鍵排列是對稱的，從 C 開始的大調音階手型，和從升 F 開始的手型完全一樣，只是整個在鍵盤上挪了位置。手型學會一次，十二個調就都是你的了，所以按鍵手風琴的演奏者常常在鋼琴家眼中難得要命的調上練音階，自己卻渾然不覺。

在鍵盤式手風琴上，指法像鋼琴一樣隨調而變，但左手會回報你下的功夫：Stradella 低音系統以一套可預測的幾何關係，給出每個音級的根音，而任何一個調的主、下屬和屬，彼此都在三顆按鍵之內。把右手音階和左手和弦排一起練，這個調就不再只是一條知識，而是一個身體記得的位置。

在低音提琴上，音階同時就是音準訓練，因為你沒有琴格，也沒有任何地方可以躲。慢慢拉，每個音都停住，只要有空弦可用，就拿它來核對：在 G 大調裡，讓空弦 G 和空弦 D 與你按出的音一起響，聽那種拍音消失。這不是初學者的練習。A&G Academy 的樂團演奏者排練前都這麼做，任何明白事理的人也都這麼做。

常見問題

大調和小調真正的差別是什麼？

差別在全音和半音的排列。小調把大調音階的第三、第六和第七級各降低半音。耳朵聽到的差異主要來自第三級：大三度在主音上方四個半音，小三度則是三個半音。彈一次 C、E、G，再彈 C、降 E、G，你馬上就聽得出來。

我該練哪一種小調音階？

先學自然小調，因為它和調號一致，不必多想。接著加上和聲小調，因為小調作品裡你真正會遇到的和弦，都是從它產生的。旋律小調排第三，它最重要的用途在旋律寫作和爵士即興。

學會所有音階要多久？

每天專心練十分鐘，大多數成人學生幾個月內就能把常用的大調練穩，一年左右掌握全部十二個調。按鍵式手風琴的演奏者通常更快，因為同一個指法手型可以直接搬到各個調上。目標不是速度，而是均勻的音色和可靠的音準。
