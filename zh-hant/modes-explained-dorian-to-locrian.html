調式詳解，從 Dorian 到 Locrian

七種調式就是從大調音階的每一級起頭的音階。每一種聽起來是什麼樣，哪個音定義了它，又能在哪裡聽到它。

2026-07-02

一句話回答

七種調式，就是從大調音階的七個音級分別起頭所彈出的音階。在 C 大調音階裡從 D 開始，就是 Dorian；從 E 開始，就是 Phrygian，以此類推。音一樣，主音不同，因此全音半音的排列不同，性格也不同。

同樣的音，不同的中心

從 C 到 C 彈一遍白鍵，你得到的是大調音階，在調式的說法裡叫做 Ionian。現在從 D 到 D 彈白鍵。一個音都沒變，但全音和半音的排列轉了一圈，音階聽起來就很不一樣。這就是 Dorian，第二種調式。

七個起點，七種調式：從 C 起的 Ionian、從 D 起的 Dorian、從 E 起的 Phrygian、從 F 起的 Lydian、從 G 起的 Mixolydian、從 A 起的 Aeolian，以及從 B 起的 Locrian。這些希臘名稱來自中世紀的理論家，他們把古希臘術語套到這些音階上，套得並不太準確。誰都不必為這套命名辯護。

最關鍵、也最需要時間才能真正體會的一點是：決定調式的，是音樂把哪個音當成家，而不是有哪些音可用。一首只用白鍵的曲子，如果不斷回到 D、在 D 上終止、把 D 當成歇腳處，那它就是 D Dorian。如果它不斷回到 C，那就只是 C 大調。重心一換，上面的一切也跟著改變。

七種調式，各有什麼作用

學調式最快的方法，是把它和同一個起始音上的大調或小調音階比較，找出不同的那一兩個音。那個差別就是這個調式的指紋。

Ionian 就是大調音階本身。Lydian 是第四級升高的大調：F Lydian 是 F、G、A、還原 B、C、D、E。用還原 B 取代降 B，帶來一種開闊、飄浮、略帶失重的感覺。電影作曲家在需要驚奇或飛翔的場景時，總是用上它。

Mixolydian 是第七級降低的大調：G Mixolydian 是 G、A、B、C、D、E、還原 F。它有大三度，所以明亮，但降低的第七級去掉了導音往主音的拉力。結果聽起來是穩穩扎根，而不是努力往前衝，這也是為什麼它主宰了搖滾、源自藍調的寫作，以及大量的凱爾特舞曲。

Dorian 是第六級升高的小調：D Dorian 是 D、E、F、G、A、還原 B、C。色彩是小調，卻有一個明亮的音，讓它不至於聽來哀傷。想想 Scarborough Fair、So What，或五〇年代末大部分的調式爵士。

Aeolian 就是自然小調音階。Phrygian 是第二級降低的小調：E Phrygian 是 E、還原 F、G、A、B、C、D。音階最底部的那個半音，帶來佛朗明哥賴以建立的那種西班牙式、陰暗而具儀式感的性格。Locrian 把第二級和第五級都降低，破壞了主音上方穩定的純五度，讓這個調式幾乎無處立足。它大體上是理論上的奇珍，誠實的老師也會這樣承認。

讓調式聽得出來

如果和聲不支持，調式會立刻退回普通的大調或小調。在 C 大三和弦上彈 D Dorian，耳朵聽到的是 C 大調，外加一段剛好從 D 開始的旋律。

解決辦法是持續音或靜止不動的低音。按住一個低音 D，在上面彈白鍵，Dorian 就再明顯不過。天生使用調式的音樂正是這麼做的：風笛、搖弦琴、印度古典音樂，還有不少民間小提琴曲目，底下都有一個持續的主音，而調式寫作本來就是在這種支撐下發展出來的。

另一個方法是使用這個調式本身的和弦，並避開屬到主的終止式，因為正是這個終止式定義了大調和小調，它會把任何調式拉回大小調。Dorian 倚重小調主和弦和大調四級和弦，也就是 D 小調到 G 大調。Mixolydian 使用大調主和弦和降七級大和弦，也就是 G 大調到 F 大調。避開導音，調式就能存活。

回到樂器上的調式

手風琴特別適合演奏調式，因為左手正好可以提供調式需要的持續音。按住一顆基本低音鍵，讓它貫穿整個樂句，或讓低音和它的五度音交替，你就有了一支風笛。在自由低音或轉換式的琴上，你可以在右手移動時無限延長一個真正的持續低音，這是任何鋼琴都做不到的。

Stradella 和弦排有一點要小心：預設的七和弦按鍵含有導音，會把你的 Dorian 直接拉回某個調。做調式伴奏時，優先使用單純的基本低音排和大、小三和弦，七和弦按鍵就別碰。

在低音提琴上，空弦是調式的禮物。E、A、D、G 讓你幾乎毫不費力就能在任何民間調式底下撐起持續音，而空弦在調式旋律下方的共鳴，是任何按出來的音都無法重現的聲音。一個 D 持續音托著 Dorian 旋律，弓慢慢拉，左手什麼都不做，這是歐洲民間音樂裡最古老的招數，至今仍最有效。我們在 A&G Academy 第一年的合奏課上就用它，正是因為它大約十秒鐘就能讓理論變得聽得見。

常見問題

調式和音階有什麼不同？

調式本身就是一種音階，所以兩個詞有重疊。實際上，調式通常指大調音階的七種輪轉之一，每一種有不同的主音。真正重要的區別在功能：調式音樂避開定義大小調的屬到主終止式，而且常常以持續音為依託。

我該先學哪一種調式？

Dorian 和 Mixolydian，因為它們在實際曲目中最常出現，而且各自和一個熟悉的音階只差一個音。Dorian 是第六級升高的自然小調；Mixolydian 是第七級降低的大調。先把這兩個學好，再學 Lydian。Locrian 無限期延後也完全沒關係。

為什麼彈調式常常聽起來就像大調音階？

因為底下的和聲仍在確立大調。如果你在 C 大調和弦上彈 D Dorian，耳朵聽到的就是 C 大調。在低音放一個持續的 D，使用這個調式本身的和弦，並避開導音，調式就會立刻顯現。調式需要和聲的支撐才能存在。
