終止式是什麼？

終止式是結束一個樂句的那組和弦，它的作用就像標點。四種主要類型，以及怎麼聽出、怎麼彈出每一種。

2026-06-23

一句話回答

終止式是結束一個樂句的那一對和弦。它的作用就像標點符號：有些終止式是句號，有些是逗號，有些則是刻意的驚喜。用了哪些和弦、以什麼順序，決定了這個樂句在聽眾耳中有多完整。

音樂為什麼需要標點

說話有句號、逗號和問號，少了它們，一段話會讓人讀得精疲力盡。音樂也有同樣的問題，解決方法也一樣。樂句需要結尾，而結尾需要分等級：有些是最終的，有些是暫時的，有些則模稜兩可。

這個分級由終止式來完成，也就是樂句最後的兩個和弦。聽眾不需要任何訓練就能辨認。在一群非音樂人面前彈一首聖詩的結尾，提早一個和弦停下，看看大家多不自在。這套知識早已內建；樂理只是幫它取了名字。

這些名稱用羅馬數字表示建立在音階各級上的和弦。在 C 大調中，I 是 C 上的和弦，IV 是 F 上的和弦，V 是 G 上的和弦，vi 是 A 小三和弦。依慣例，小寫數字代表小和弦。其中兩個音級的名稱值得記住：第五級是屬音，第四級是下屬音。

正格終止：句號

V 到 I，屬到主。在 C 大調中就是 G 到 C。這是調性音樂中最強的結尾，你所熟悉的音樂大約九成都以它結束。

它之所以有效，是因為屬和弦包含導音，也就是音階的第七級，它位在主音下方半音，在往上走一步之前聽起來都未解決。在 C 大調中這個音是 B，而 B 向 C 靠攏的力道非常實在。為屬和弦加上七音，變成 G、B、D、F，就多了第二個不穩定的音：F 想往下走到 E。兩個聲部從相反方向拉向同一個和弦，這就是屬七和弦到主和弦如此具決定性的原因。

最具終結感的版本，是把根音放在低音，先 G 再 C，並把主音放在最後一個和弦的最上方。削弱其中任何一個條件，終止感就會變軟，但仍然有效，作曲家就是這樣讓一首曲子經過二十個樂句結尾，才抵達真正的結尾。

其他三種

半終止停在 V 上，而不是從 V 離開。在 C 大調中，就是任何和弦到 G。它聽起來像逗號，或像揚起的眉毛：樂句只是暫停，還沒結束，後面一定還有東西。民謠和古典主題中的問答樂句，幾乎總是用半終止作為問句，用正格終止作為答句。

變格終止是 IV 到 I，在 C 大調中就是 F 到 C。這就是聖詩結尾的「阿們」，也是這個名稱流傳下來的原因。它沒有導音的半音拉力，所以是安頓下來，而不是解決。更溫暖、更放鬆，也少了爭辯的意味。

阻礙終止，有時稱為假終止，先鋪陳 V，然後走向 I 以外的和弦，通常是 vi。在 C 大調中，就是 G 到 A 小三和弦。耳朵被承諾了 C，得到的卻是 A 小三和弦，它和 C 和弦有兩個共同音，但它是小和弦，也不是家。作曲家用它來延長看似即將結束的樂句，把最後的終止式再延後十六小節。這在音樂上就相當於有人伸手要開門時，你清了清喉嚨。

在真實的音樂中聽出終止式

聆聽終止式，是從把音樂聽成一串音符，到聽出其結構的最快途徑。隨便放一首 Mozart 的小步舞曲，數一數樂句：你幾乎一定會發現四小節為一個單位，第一個以半終止結束，第二個以正格終止結束。

在探戈中，雖然節奏已經離維也納很遠，古典的終止式仍然主導著結尾。聽 Gardel，你會聽到正格終止帶著略帶戲劇性的延遲到來，和聲被拖住，讓歌手有時間發揮。在藍調中，十二小節曲式本質上就是朝正格終止的一段長長鋪陳，並在第九小節帶有阻礙終止的感覺。

一個實用的練習習慣：彈一個樂句，停在倒數第二個和弦，然後唱出接下來應該出現的音。如果你唱對了，就表示你已經內化了這個終止式。如果作曲家實際寫的讓你感到意外，你就找到了值得研究的東西。

演奏終止式，而不只是抵達它

知道自己在彈哪一種終止式，應該會改變你在身體上的做法。結束整個樂章的正格終止需要重量和時間；樂句中間的半終止則幾乎都不需要，因為強調逗號會讓句子聽起來斷掉。

對手風琴手來說，這是風箱的功夫。最後的正格終止，在屬和弦上稍微加大風箱壓力，再有控制地放鬆進入主和弦，而且要等和弦響過之後風箱才停下。半終止則相反：放輕，並讓風箱繼續移動，讓之後的靜默仍然有生命。在左手，Stradella 低音系統把屬和下屬的按鍵就放在主音的兩側，所以 V 到 I 和 IV 到 I 都只要移動一顆按鍵。學會聽出這兩個鄰居的差別，你就學會了句號和「阿們」的差別。

在低音提琴上，終止式是低音線承載最多資訊的地方。在兩個和弦下都拉根音，會讓終止感最強；拉屬和弦的三音，也就是 C 大調中 G 和弦下的 B，再往上半音到 C，則會讓它更圓滑、不那麼強調。這個選擇屬於低音提琴手，而在 A&G Academy，我們會花整堂課處理這類問題，因為它決定了你是在結束一個樂句，還是只是停下來。

常見問題

音樂中最常見的終止式是哪一種？

正格終止，屬到主，寫作 V 到 I。在 C 大調中，就是 G 和弦接 C 和弦。這是最強的結尾，因為屬和弦包含主音下方半音的導音，耳朵在它往上走之前都會覺得未解決。大多數有調性的曲子都這樣結束。

正格終止和變格終止有什麼不同？

正格終止從第五級到第一級，在 C 大調中是 G 到 C，帶有導音的半音拉力，因此果斷有力。變格終止從第四級到第一級，F 到 C，沒有導音。它是溫和地安頓下來，而不是有力地解決，這也是聖詩用它來唱「阿們」的原因。

為什麼有些樂句結束了，聽起來卻沒結束？

因為它們以半終止結束，停在屬和弦上，而沒有走到主和弦。屬和弦本質上不穩定，所以耳朵把這個停頓當成逗號，等待後續。作曲家把它和正格終止配對，形成問答樂句，這是調性旋律的基本單位。
