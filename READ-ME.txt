accordion.sg — website (19 Sep 2026)

HOW TO USE IT
  Locally : double-click index.html. Everything works offline except the
            YouTube players, the web fonts and the score PDF previews,
            which need a connection.
  On the web: upload EVERYTHING in this folder to your web root. Done.
            No build step, no framework, nothing to install.

LANGUAGES
  Every page contains ALL SEVEN languages in the one HTML file —
  English, Русский, 中文, 日本語, 한국어, Bahasa Melayu, தமிழ்.
  The menu in the header switches them instantly, with no page reload
  (the Score Library reloads once, because it builds its index on load).
  The choice is remembered, so it carries across pages.
  A direct link can force a language:  about.html?lang=ja
  Those ?lang= URLs are what the hreflang tags and the sitemap point at.

EDITING
  Page text     : open the .html file. Each language sits in its own
                  <div class="lx" data-l="ru"> … </div> block. Edit the one
                  you want; the others are untouched.
  Menus, buttons, labels: the window.ACCSG_I18N block near the top of each
                  file (generated from the same source for every page).
  Colours/layout: style.css
  Prices, Stripe links, WhatsApp number, the accordion catalogue:
                  the top of script.js — one config block.
  Score list    : scores-data.js (743 records).
