调式详解，从多利亚到洛克里亚

七种调式就是从大调音阶的每一级起头弹出来的音阶。每一种听起来是什么样，是哪个音定义了它，又能在哪里听到它。

2026-07-02

一句话回答

七种调式，就是从大调音阶的七个音级各自起头弹出来的音阶。在 C 大调音阶里从 D 起头，得到多利亚；从 E 起头，得到弗里几亚，以此类推。音是同一批，主音不同，于是步距的排列不同，性格也就不同。

同样的音，不同的重心

从 C 到 C 弹一遍白键，你得到的是大调音阶，在调式的说法里它叫伊奥尼亚。现在从 D 到 D 弹白键。一个音都没变，全音和半音的排列却转了一圈，音阶听起来相当不一样。那就是多利亚，第二种调式。

七个起点给出七种调式：从 C 起的伊奥尼亚、从 D 起的多利亚、从 E 起的弗里几亚、从 F 起的利底亚、从 G 起的混合利底亚、从 A 起的爱奥利亚，以及从 B 起的洛克里亚。这些希腊名字是中世纪理论家留下来的，他们把古希腊的术语安到了这些音阶上，安得并不怎么准。谁都不必为这套命名辩护。

最关键、也最花时间才想通的一点是：定义一种调式的，是音乐把哪个音当作家，而不是有哪些音可用。一首只用白键的曲子，如果不断回到 D、终止在 D、把 D 当成落脚处，那它就是 D 多利亚。如果它不断回到 C，那它不过是 C 大调。把重心挪一挪，上面的一切也跟着变。

七种调式，各自在做什么

学一种调式最快的办法，是把它和同一个起始音上的大调或小调音阶比一比，看出那一两个不同的音。那个差别就是这种调式的指纹。

伊奥尼亚就是大调音阶本身。利底亚是升高四级的大调：F 利底亚是 F、G、A、还原 B、C、D、E。那个还原 B 取代了降 B，带来一种敞开的、悬浮的、略微失重的感觉。电影作曲家在需要惊奇或飞翔的场面时，反复来拿它。

混合利底亚是降低七级的大调：G 混合利底亚是 G、A、B、C、D、E、还原 F。它有大三度，所以明亮，但降低的七级把导音往主音上的那股拉力拿掉了。结果听起来是扎根的，而不是在使劲往前够，所以摇滚、布鲁斯一路的写作和大量凯尔特舞曲都被它占着。

多利亚是升高六级的小调：D 多利亚是 D、E、F、G、A、还原 B、C。底色是小调，却有一个明亮的音，不让它听起来哀怨。想想 Scarborough Fair，或者 So What，或者五十年代末大部分的调式爵士。

爱奥利亚就是自然小调音阶。弗里几亚是降低二级的小调：E 弗里几亚是 E、还原 F、G、A、B、C、D。音阶最底下那个半音，给了它弗拉门戈赖以成立的那种西班牙式的、暗沉而带仪式感的性格。洛克里亚把二级和五级都降低，于是主音上方那个稳定的纯五度被毁掉了，这种调式几乎没有可以站住的地方。它基本上是个理论上的好奇心，诚实的老师会直说。

怎么让一种调式真的听得出来

如果和声不支持它，调式会立刻塌回普通的大调或小调。在 C 大三和弦上弹 D 多利亚，耳朵听到的就是 C 大调，外加一支碰巧从 D 开始的曲调。

解药是持续音或者一个不动的低音。按住一个低的 D，在它上面弹白键音，多利亚就无可争辩了。天生使用调式的那些音乐，走的正是这条路：风笛、绞弦琴、印度古典音乐，还有相当一部分民间提琴曲目，下面都有一个持续的主音，而调式写作本来就是在这种支撑下长出来的。

另一条路是使用这种调式自带的和弦，并且避开属到主的终止式——正是那个终止式定义了大调和小调，它会把任何调式拽回它们那边去。多利亚倚靠的是小调主和弦和大调的四级和弦，d 小调到 G 大调。混合利底亚用的是大调主和弦和大调的降七级和弦，G 大调到 F 大调。避开导音，调式就活得下来。

回到乐器上的调式

手风琴在调式演奏上装备得出奇地好，因为左手可以恰好提供调式需要的那个持续音。按住一个单独的基础低音按钮，让它响过整个乐句，或者让低音和它的五度交替出现，你就有了一台风笛。在自由低音或转换式的琴上，你可以在右手移动的同时无限地保持一个真正的持续低音，这是钢琴做不到的。

斯特拉德拉的和弦排上有一个需要当心的地方：预设的七和弦按钮里含有导音，它会把你的多利亚直接拽回某个调里去。做调式伴奏时，优先用纯粹的基础低音排和大、小三和弦，别碰那些七和弦按钮。

在低音提琴上，空弦是调式送来的礼物。E、A、D、G 让你几乎不费力就能在任何民间调式下面托起一个持续音，而一根空弦在调式曲调下方的那种共鸣，任何按下去的音都复制不出来。一个 D 持续音托着一支多利亚旋律，弓子慢慢拉开，左手什么都不做——这是欧洲民间音乐里最老的一招，也仍旧是最有效的一招。在 A&G Academy 的第一年合奏课上我们就用它，正是因为它能在十秒钟左右把理论变成听得见的东西。

常见问题

调式和音阶有什么区别？

调式就是一种音阶，所以这两个词是重叠的。实际用法里，调式通常指大调音阶的七种旋转形式之一，每一种有不同的主音。真正要紧的区别在功能上：调式音乐避开那个定义了大调和小调的属到主终止式，而且常常落在一个持续音上。

应该先学哪一种调式？

多利亚和混合利底亚，因为它们在真实曲目里出现得最多，而且各自只和一个熟悉的音阶差一个音。多利亚是升高六级的自然小调，混合利底亚是降低七级的大调。把这两个学扎实，然后学利底亚。洛克里亚无限期往后放也没有任何损失。

为什么弹调式常常听起来就是大调音阶？

因为下面的和声还在定义那个大调。如果你在 C 大调和弦上弹 D 多利亚，耳朵听到的就是 C 大调。在低音上放一个持续的 D，使用这个调式自带的和弦，避开导音，调式立刻就立住了。调式需要和声的支撑才能存在。
