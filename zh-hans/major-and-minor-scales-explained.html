大调与小调音阶详解

大调和小调的区别，在于音阶内部全音和半音的排列。这里讲清楚那个排列、小调的三种形式，以及三级音为什么最关键。

2026-05-12

一句话回答

大调音阶是一串固定的步距：全音、全音、半音、全音、全音、全音、半音。小调把这个排列里的三级、六级和七级降低。你的耳朵听出的明亮与暗淡之别，主要就来自那个被降低的三级音。

音阶是一个排列，不是一串音名

多数人第一次遇见大调音阶，是把它当成 do re mi 的声音，或者当成从 C 到 C 的那一排白键。两种说法都没错，但都不是有用的定义。有用的定义是一串距离的排列。

先说两个词。半音是西方音乐里最小的常规步距，从钢琴上任何一个键到紧挨着的下一个键，无论黑白。全音是两个半音。在低音提琴上，低把位里的一个半音大致是相邻两指之间的距离，一个全音大致是一指到三指的距离。

从起始音往上数，大调的排列是：全音、全音、半音、全音、全音、全音、半音。从 C 开始套用，得到 C、D、E、F、G、A、B、C，正好全是白键。把同一个排列从 D 开始套用，得到 D、E、升 F、G、A、B、升 C、D。那两个升号不是装饰，它们是维持这个排列所必须的，而正是这个排列，让声音一听就是大调。

小调音阶，以及那个降低的三级

自然小调用的是同样七个字母，把三级、六级和七级各降低一个半音。C 大调是 C、D、E、F、G、A、B。c 自然小调是 C、D、降 E、F、G、降 A、降 B。

这三处改动里，三级几乎承担了全部的情绪工作。从 C 往上到 E 是四个半音，叫大三度。从 C 往上到降 E 是三个半音，叫小三度。就是这一个半音，构成了多数听者称为明亮的声音和多数听者称为暗淡、悲伤或严肃的声音之间的全部差别。在任何一台键盘上，四秒钟就能验证：先弹 C、E、G，再弹 C、降 E、G。别的什么都没变。

值得抵制一下“小调等于悲伤”这种省事的说法。大量舞曲、几乎全部探戈，以及东欧民间曲目里很大一块，都活在小调里，而且一点都不悲伤。小调是一种颜色，不是一种情绪。

小调为什么有三种形式

自然小调有一个实际的弱点：它的七级音在主音下方整整一个全音。在 c 小调里，那个七级是降 B，而降 B 并不急着往 C 上靠。想要一个果断的到达，音乐就需要一个在主音下方半音的音，一个不解决就听着没完的音。

于是和声小调把七级重新升回去：C、D、降 E、F、G、降 A、还原 B、C。还原 B 使劲往 C 上拉，而建在 G 上的属和弦变成了大三和弦，小调终止式的那股劲头就是从这儿来的。代价是降 A 和还原 B 之间那道三个半音的口子，这个音程听着明显带异域味，唱起来也别扭。

旋律小调的办法是，在上行时把六级也一起升高，把那道口子抹平：C、D、降 E、F、G、还原 A、还原 B、C。按传统做法，下行时它回到自然小调，因为下行的线条并不需要往主音上靠。爵士的实际用法里，升高的那个形式常常上下行都用。三种形式，一个音阶，各自解决一个不同的问题。

关系调与同主音调

有两种关系值得点出名字，因为它们总被弄混。关系调共用调号。C 大调和 a 小调都没有升号降号；关系小调总是从大调主音往下一个小三度开始。两者包含的音完全相同，区别只在于音乐把哪一个音当作家。

同主音调共用的则是主音。C 大调和 c 小调都从 C 开始，调号却不同，相差三个降号。作曲家在同主音调之间来回切换，为的是立刻见效的戏剧性：家还在原地，颜色却整个翻了过去。舒伯特靠这一手撑起了半个创作生涯。

回到乐器上练音阶

在半音阶键钮式手风琴或巴扬上，音阶指法在各个调之间的重复方式，会让钢琴演奏者觉得有点不公平。因为按钮排列是对称的，从 C 开始的大调音阶的手型，和从升 F 开始的手型是同一个，只是整体挪了位置。手型学会一次，十二个调就都是你的了，所以键钮手风琴的演奏者常常在钢琴家眼中残酷得要命的调上练音阶，自己却毫无察觉。

在键盘式手风琴上，指法像钢琴一样随调而变，但左手会回报你下的功夫：斯特拉德拉低音板用一套可预测的几何关系，给出每一个音级的根音，而任何一个调的主、下属和属，都在相隔三个按钮之内。把右手的音阶和左手的和弦排放在一起练，这个调就从一条知识变成了一个身体上的位置。

在低音提琴上，音阶同时就是音准训练，因为你没有品，也没有任何可以藏身的地方。慢慢拉，每个音都停住，只要旁边有空弦就拿它来核对：在 G 大调上，让空弦 G 和空弦 D 与你按下的音同时发声，听那种拍音消失。这不是初学者的练习。A&G Academy 的乐队演奏者排练前就这么做，任何头脑清楚的人也都这么做。

常见问题

大调和小调真正的区别是什么？

是全音和半音的排列。小调把大调音阶的三级、六级和七级各降低一个半音。听觉上的活主要由三级完成：大三度在主音之上四个半音，小三度是三个半音。弹一遍 C、E、G，再弹 C、降 E、G，你立刻就能听出来。

该练哪一种小调音阶？

先学自然小调，因为它和调号一致，不用额外动脑。然后加上和声小调，因为小调作品里你真正会遇到的那些和弦，正是它生出来的。旋律小调排第三，它最要紧的场合是旋律写作和爵士即兴。

学完所有音阶要多久？

每天十分钟专注地练，多数成年学习者几个月内就能把常用的大调稳住，一年左右拿下全部十二个调。键钮式手风琴的演奏者通常更快，因为一个指法手型可以在各调之间平移。目标不是速度，而是均匀的音色和可靠的音准。
